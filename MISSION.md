# Mission: Lolos interview Fullstack Developer .NET + Angular (mid-level)

## Why
Pindah dari stack TypeScript/Node.js/React ke posisi fullstack .NET 8 + Angular 16. Dalam 3 hari harus bisa menjawab pertanyaan konsep dengan yakin dan mengerjakan live coding kecil.

## Success looks like
- Bisa menjelaskan alur request ASP.NET Core dan peran Controller / Service / Repository / DbContext / Config dengan bahasa sendiri dalam < 1 menit
- Bisa menjelaskan tiga DI lifetime beserta jebakannya (captive dependency)
- Bisa memberi contoh kelima prinsip SOLID dari kode Product Catalog
- Bisa mendemokan satu siklus red-green-refactor dan membedakan unit test vs integration test
- Bisa menjawab konsep Angular 16 inti (NgModule, DI, RxJS, lifecycle, forms, interceptor) dengan padanan React
- Punya 4 cerita STAR siap pakai

## Constraints
- 3 hari, 6–8 jam/hari
- Fokus **konsep untuk interview** (permintaan user); praktik kode mengikuti [ROADMAP.md](./ROADMAP.md)
- Bahasa Indonesia, istilah teknis tetap bahasa Inggris
- Versi: .NET 8, Angular 16 (bukan 17+)

## Out of scope
- System design berat, microservices, CQRS penuh
- Clean Architecture multi-project secara praktik (cukup dijelaskan lisan)
- Angular 17+ (control flow `@if`, signals stabil)
