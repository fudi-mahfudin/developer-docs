USE ProductCatalogLab;
SET STATISTICS IO, TIME ON;

SELECT TOP (10) Id, Name, Price
FROM dbo.Product
WHERE Price > 100 AND Name <> N'Contoh & Co'
ORDER BY Price DESC;

Latihan tulis query

Tulis query untuk menghitung jumlah Product per Category, urut dari yang terbanyak.

Lihat jawaban 
SELECT c.Name, COUNT(*) AS ProductCount
FROM dbo.Product p
JOIN dbo.Category c ON c.Id = p.CategoryId
GROUP BY c.Name
ORDER BY ProductCount DESC;

Jawaban tidak dinilai otomatis. Jalankan query Anda di lab, lalu bandingkan hasilnya.
