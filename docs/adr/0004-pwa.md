# 0004 · Progressive Web App sebagai progressive enhancement

Status: diterima (2026-11-20)

## Konteks

Materi hanya bisa dibaca saat online, atau dari `file://` di laptop yang punya salinan repo. Materi ini ingin dibaca di HP, termasuk tanpa sinyal, dan dibuka seperti aplikasi. Di sisi lain, `file://` adalah kontrak utama komponen bersama (`assets/README.md`, ADR 0003), dan menambah lesson tidak boleh jadi lebih repot. Spec lengkap: `.scratch/pwa/spec.md`.

## Keputusan

- **PWA hanya ada di artefak deploy.** File sumber HTML tidak berubah. `scripts/build-pwa.js` menyalin situs ke `_site/`, menyuntik tag PWA (manifest, theme-color, ikon, `assets/pwa.js`) ke `<head>` setiap HTML, lalu membuat `sw.js`. Di `file://` semuanya berperilaku seperti sebelumnya.
- **Workbox membuat daftar precache otomatis** dengan hash revisi. Tidak ada daftar file yang diedit manual, sehingga lesson baru otomatis ikut offline dan file yang berubah otomatis ter-update.
- **Strategi cache:** semua materi di-precache (sekitar 3–4 MB). Navigasi halaman memakai network-first dengan timeout 3 detik, lalu precache, lalu `offline.html`. Aset memakai cache-first. Update berjalan senyap (`skipWaiting` + `clientsClaim`).
- **Yang tidak dideploy:** `tests/`, `docs/`, `scripts/`, `pdf/`, `node_modules/`, `package*.json`, dan semua path berawalan titik (`.scratch/`, `.github/`, dotfile). File `*.md` dan `star/` **ikut**, karena HTML menautkannya.
- **Deploy:** GitHub Actions (`.github/workflows/deploy.yml`) pada push ke `main` menjalankan `npm test`, lalu build, lalu deploy ke Pages. Commit dengan tes merah tidak tayang. Hanya `main` yang dideploy.
- **Tooling di root:** `package.json` (devDependencies untuk build, ikon, dan preview) dan folder `scripts/`, sebagai tambahan atas struktur ADR 0001. Tes tetap jalan dengan `node --test` tanpa `npm install`.
- **Ikon:** satu sumber `assets/icon.svg`. PNG di `assets/icons/` di-generate dengan `npm run icons` lalu di-commit.

## Konsekuensi

- Penulis lesson tidak perlu melakukan apa pun untuk PWA. Tag PWA **tidak** ditulis di HTML sumber.
- Untuk mencoba SW, offline, atau install, jalankan `npm run preview` (`http://localhost:8080`). Membuka file langsung tetap lewat `file://`.
- Jekyll tidak lagi berjalan. Salinan HTML dari markdown (mis. `GLOSSARY.html`) hilang, dan `*.md` disajikan apa adanya, sama seperti yang selama ini dituju tautan di HTML.
- Branch selain `main` (mis. `materi-fullstack`) tidak tayang sampai di-merge ke `main`.
- Tautan ke `.scratch/` (mis. dari `dotnet/index.html`) tetap 404 di situs, sama seperti sebelumnya. Tes `tests/shared/build-pwa.test.js` menolak tautan baru ke file yang tidak dideploy.
