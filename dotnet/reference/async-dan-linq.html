Dua larangan di ASP.NET Core [2]

  • .Result / .Wait(): memblokir thread, banyak blocking call → thread pool starvation. Buat seluruh call stack async.
  • async void: tidak bisa di-await, exception tidak bisa ditangkap pemanggil, request selesai pada await pertama. Hanya untuk event handler; selain itu Task.

IEnumerable<Product> s = _db.Products; s.Where(p => p.Price > 100).ToList();
// ✅ filter, proyeksi, paging selagi IQueryable; ToListAsync terakhir
await _db.Products.Where(p => p.Price > 100).Select(...).ToListAsync();

Jawaban 60 detik

Where hanya membangun IQueryable (expression tree); itu deferred execution. SQL baru dikirim saat hasil dikonsumsi, di sini oleh ToListAsync, dan karena masih IQueryable filternya jadi WHERE di database. await tidak memblokir thread selama I/O; .Result memblokir dan bisa menyebabkan thread pool starvation. Jadi call stack async dari Controller sampai Repository, seperti async/await di Express.
