Interface vs abstract class [5]

  • Interface: kontrak tanpa instance field/constructor. Satu class boleh banyak interface. Contoh: IProductRepository.
  • Abstract class: tidak bisa di-new; boleh punya field, constructor, method jadi. Hanya satu base class per class. Contoh: RepositoryBase<T>.

Jawaban 60 detik

class = reference type, struct = value type (disalin, untuk data kecil). record = modifier di atas keduanya yang memberi value equality, ToString, dan with; positional record class immutable. DTO adalah data murni, jadi ditulis sebagai record. Entity EF Core tetap class karena EF Core butuh reference equality.
