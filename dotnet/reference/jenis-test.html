WebApplicationFactory<Program> [1]

  • Paket Microsoft.AspNetCore.Mvc.Testing; menjalankan app di TestServer in-memory, tanpa deploy.
  • public partial class Program { } di Program.cs supaya test project bisa memakai Program (atau InternalsVisibleTo).
  • CreateClient() → HttpClient ke TestServer. IClassFixture<ApiFactory> berbagi factory per class.
  • Override ConfigureWebHost → builder.ConfigureServices (jalan setelah Program.cs) untuk mengganti DbContext.
  • Per test: WithWebHostBuilder(b => b.ConfigureTestServices(...)).

Jawaban 60 detik

Jenis test: unit = satu komponen terisolasi, I/O di-mock, milidetik; integration = beberapa komponen bersama sampai DB; E2E = dari UI. Piramida: makin tinggi makin sedikit. API diuji dengan WebApplicationFactory (TestServer in-memory, CreateClient), DbContext diganti SQLite/Testcontainers.

Test double: stub = jawaban siap, tidak di-assert; mock = panggilannya di-Verify; fake = implementasi ringan (SQLite in-memory). Mock batas I/O; jangan mock Entity/DTO, SUT, method private, atau DbSet untuk query.
