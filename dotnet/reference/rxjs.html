Mencegah memory leak

  1. async pipe (utama): *ngFor="let p of products$ | async". Subscribe dan unsubscribe otomatis.
  2. takeUntil(this.destroy$) di akhir pipe; ngOnDestroy() { this.destroy$.next(); this.destroy$.complete(); }
  3. takeUntilDestroyed() (@angular/core/rxjs-interop): ada di v16 tapi masih developer preview.

Berbahaya: subscribe manual ke stream yang tidak pernah complete (interval, valueChanges, Subject di service) tanpa cleanup. React: useEffect tanpa cleanup.

Jebakan interview

  1. Lupa subscribe pada http.get → tidak ada request.
  2. mergeMap di search box → race condition, hasil lama menimpa.
  3. catchError di stream luar → search box mati setelah error pertama.
  4. switchMap untuk DELETE massal → sebagian request dibatalkan.
