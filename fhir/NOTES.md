# Notes

- Workspace ini adalah track terpisah dari track .NET + Angular di `dotnet/` (satu mission per workspace). Komponen bersama (`style.css`, `quiz.js`, `bank.js`, `bank-quiz.js`, `review.js`, `order.js`, `timer.js`) dipakai dari `../../assets/`; bank soal track ini ada di `fhir/assets/questions/NNNN.js`. Format soal sama dengan `assets/README.md` di root.
- User paling kuat di ekosistem JavaScript (TypeScript, Node.js, React). Semua contoh kode memakai TS/Node/React, bukan .NET. Jembatani ke pengalaman REST/JSON/OAuth yang sudah dikenal.
- Fokus **konsep untuk interview**, tanpa implementasi: tidak ada lab, tidak ada server. Potongan JSON dan TS hanya untuk dibaca dan dijelaskan.
- Profil posisi: fullstack (backend Node + frontend React), mid-level. FHIR R4.
- Bahasa Indonesia, istilah teknis bahasa Inggris.
- Agent yang membuat lesson wajib mengikuti skill `/teach` (baca `~/.claude/skills/teach/SKILL.md` langsung kalau skill tidak bisa dipanggil) dan mengambil fakta dari sumber primer (hl7.org/fhir/R4, SMART App Launch IG, Bulk Data Access IG, dokumentasi SATUSEHAT), bukan dari ingatan model. Detail SATUSEHAT yang tidak bisa diverifikasi publik ditandai "belum terverifikasi".
- **Struktur sejak 2026-10-27 (ADR 0002):** 29 lesson ±20 menit, self-paced, tanpa deadline. Lesson lama 0001–0007 dipecah tanpa ditulis ulang (spec `.scratch/restruktur-fhir/spec.md`). Catatan per lesson di bawah memakai **nomor lama**; padanannya: lama 0001 → 0001–0003, 0002 → 0004–0007, 0003 → 0008–0011, 0004 → 0013–0016, 0005 → 0017–0020, 0006 bagian 1 → 0022–0023, bagian 2 → review 0012/0021/0027, bagian 3 → 0028, bagian 4 → 0029, 0007 → 0024–0026. Slug topik tidak berubah.
- Hanya hasil review 0012, 0021, 0027 yang dicatat sebagai bukti penguasaan. Kuis di lesson lain adalah feedback cepat. Aturan lulus per topik: kuis benar **dan** soal lisan lulus (satu soal lisan lulus kalau ≥ 2/3 poin checklist dicentang, `assets/bank.js`); topik tanpa soal lisan yang ditarik paling jauh "Kuis lulus, lisan belum diuji". Saat user menempelkan ringkasan "Hasil Review …": tulis learning record hanya untuk topik Lulus (sebut seed dan skor), catat topik "lisan belum diuji" di NOTES saja, dan catat `Topik lemah: …` sebagai baris "Topik lemah FHIR <review>: slug1, slug2" lalu masukkan slug itu ke `data-topics` review 0027.
- Cerita STAR tidak dibuat baru: 4 cerita di `../star/draf-star.md` di-reframe ke konteks health-tech di lesson 0006.
- Lesson 0005 (SMART on FHIR) memakai SMART App Launch IG v2.2.0 (STU 2.2); OAuth/JWT dasar dan localStorage vs cookie tidak diulang, cukup ditautkan ke `../lessons/0017-fullstack-auth-cors-error.html`. Topik bank soal berprefiks `smart-`.
- Lesson 0001 (Fondasi FHIR) selesai: topik bank soal `dasar-v2-vs-fhir`, `dasar-rest-json`, `dasar-resource`, `dasar-versi`, `dasar-profil`. Klaim "R4 paling dominan di produksi" sengaja dibingkai sebagai pengamatan industri (tidak ada kalimat spesifikasi); posisi SATUSEHAT terhadap R4 diserahkan ke 0006.
- Lesson 0004 (JSON massal): fakta Bulk Data dari Bulk Data Access IG **v2.0.0 (STU 2)**, bukan 3.0.0 yang lebih baru; contoh streaming memakai `readline` (pola resmi) lalu `pipeline` + async generator untuk backpressure, karena dokumentasi tidak menjanjikan `readline` menjeda input selama `await`. Nilai `MAX_STRING_LENGTH` dan hasil `context.source` di reviver dicek langsung di Node 24.21.0.
- Lesson 0002 (anatomi resource JSON) memakai JSON yang diadaptasi dari contoh resmi R4 (Patient example, Encounter f001, Observation berat badan dan glukosa f001); kuis per bagian berprefiks `res-`, cheat sheet di `reference/anatomi-resource.html`. Jebakan R4 vs R5 yang disebut: `Encounter.class` Coding (R4) vs CodeableConcept (R5).
- Lesson 0003 (REST API) selesai: topik bank soal `rest-crud`, `rest-search`, `rest-include`, `rest-paging`, `rest-bundle`, `rest-versioning`, `rest-error`; cheat sheet `reference/rest-search-bundle.html`. Contoh query memakai Observation berat badan (LOINC 29463-7) dan Patient/123; padanan JS (Prisma `include`/`$transaction`, `Promise.allSettled`) hanya analogi.
- Lesson lama 0006 (SATUSEHAT + review campuran) dibangun dengan kuis topik `ss-` (14 mc + 3 lisan; fakta SATUSEHAT dari dokumentasi resmi diakses 2026-10-26, klaim tanpa sumber publik ditandai "belum terverifikasi"), seam satu kali atas 0001–0005, 6 soal tanya-jawab statis, dan reframe 4 tema `../star/draf-star.md`. Seam itu **belum pernah dikerjakan** (tidak ada hasil) dan sudah diganti tiga review tertunda (lihat atas). Skor latihan lisan di lesson biasa dan di 0028 hanya catatan, bukan bukti penguasaan.
