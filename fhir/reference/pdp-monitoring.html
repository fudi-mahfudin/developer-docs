PDP dan monitoring

Ringkasan satu halaman. Dari Lesson 0007. Pasal dibaca dari PDF resmi peraturan.bpk.go.id, diakses 2026-10-27.

Jawaban 90 detik: kenapa → apa → di mana → bagaimana

  1. Kenapa. Data kesehatan = data pribadi spesifik (UU 27/2022 Pasal 4 ayat (2) huruf a). Isi rekam medis rahasia, bahkan setelah pasien meninggal (Permenkes 24/2022 Pasal 32). Bocor → beri tahu subjek + lembaga ≤ 3×24 jam (UU PDP Pasal 46). [1] [3]
  2. Apa. Identitas, isi klinis, kredensial → drop. ID korelasi → HMAC.
  3. Di mana. Query search di URL, diagnostics, trace, Sentry, label metrik, frontend.
  4. Bagaimana. Allowlist di sumber · HMAC · audit trail (AuditEvent) terpisah dari log.

Jebakan

  • GET /Patient?identifier=…/id/nik|…: URL = data pasien. "HTTP logs, including those that only contain the URL itself, should be regarded as being as sensitive as the resources themselves." [4]
  • OperationOutcome.issue.diagnostics: teks bebas, bisa mengutip nilai input. [5]
  • text.div: narrative yang merangkum isi resource. [6]
  • Kode diagnosis sensitif (HIV, kesehatan jiwa) bocor walaupun nama dibuang. [7]
