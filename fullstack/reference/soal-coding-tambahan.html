Soal coding tambahan

Delapan soal easy–medium ekstra dengan format tujuh langkah yang sama dengan Lesson 0008 dan 0009: soal → pertanyaan klarifikasi → ide → pseudocode → implementasi JavaScript → kompleksitas → edge case.

Cara latihan: tutup semua di bawah judul soal, ucapkan pertanyaan klarifikasi dan ide dengan suara keras, tulis pseudocode di kertas dalam ±10 menit, lalu bandingkan. Setiap implementasi di halaman ini sudah dijalankan terhadap edge case-nya.

Soal 1: FizzBuzz

Soal

Untuk setiap bilangan 1 sampai n, hasilkan "Fizz" bila habis dibagi 3, "Buzz" bila habis dibagi 5, "FizzBuzz" bila habis dibagi keduanya, dan bilangan itu sendiri (sebagai string) untuk lainnya.

Pertanyaan klarifikasi

  • Dicetak ke console atau dikembalikan sebagai array?
  • Apa hasil untuk n ≤ 0?

Ide

Periksa kasus paling spesifik dulu: habis dibagi 15 (3 dan 5) harus dicek sebelum 3 atau 5 saja. "Habis dibagi" diperiksa dengan operator remainder %. [1]

Pseudocode

untuk i dari 1 sampai n:
    jika i mod 15 = 0: tambahkan "FizzBuzz"
    selain itu jika i mod 3 = 0: tambahkan "Fizz"
    selain itu jika i mod 5 = 0: tambahkan "Buzz"
    selain itu: tambahkan i sebagai string

Implementasi JavaScript

function fizzBuzz(n) {
  const out = [];
  for (let i = 1; i <= n; i++) {
    if (i % 15 === 0) out.push("FizzBuzz");
    else if (i % 3 === 0) out.push("Fizz");
    else if (i % 5 === 0) out.push("Buzz");
    else out.push(String(i));
  }
  return out;
}

Kompleksitas

Waktu O(n), ruang O(n) untuk array hasil (O(1) bila langsung dicetak).

Edge case

  • Urutan cabang: bila % 3 dicek lebih dulu, 15 menjadi "Fizz".
  • n = 0 atau negatif: array kosong.
  • Interviewer bisa menambah aturan (mis. 7 → "Bazz"): sebutkan versi yang menyusun string per aturan dari tabel [[3, "Fizz"], [5, "Buzz"]] supaya aturan baru tidak menambah cabang.

Soal 2: Angka Armstrong (jumlah pangkat digit)

Soal

Angka Armstrong adalah bilangan bulat non-negatif yang sama dengan jumlah setiap digitnya dipangkatkan banyaknya digit. Contoh: 153 = 1³ + 5³ + 3³ → true; 9474 = 9⁴ + 4⁴ + 7⁴ + 4⁴ → true; 154 → false.

Pertanyaan klarifikasi

  • Bilangan negatif dianggap apa? (Biasanya false.)
  • Boleh memakai string untuk mengambil digit, atau harus aritmetika?

Ide

Dua kali lewat digit dengan % 10 dan pembagian integer (pola dari Lesson 0008): pertama menghitung banyak digit k, kedua menjumlahkan digitk. Angka 0 punya satu digit.

Pseudocode

fungsi isArmstrong(n):
    jika n bukan integer atau n < 0: kembalikan false
    k ← banyak digit n            // 0 dihitung 1 digit
    jumlah ← 0;  x ← n
    selama x > 0:
        jumlah ← jumlah + (x mod 10)^k
        x ← x div 10
    kembalikan jumlah = n

Implementasi JavaScript

function isArmstrong(n) {
  if (!Number.isInteger(n) || n < 0) return false;
  let digits = 1;
  for (let x = Math.floor(n / 10); x > 0; x = Math.floor(x / 10)) digits++;
  let sum = 0;
  for (let x = n; x > 0; x = Math.floor(x / 10)) sum += (x % 10) ** digits;
  return sum === n;
}

Kompleksitas

Waktu O(d) dengan d banyak digit (= O(log n)), ruang O(1).

Edge case

  • 0 sampai 9: semuanya Armstrong (d¹ = d), termasuk 0 karena dihitung satu digit.
  • Angka negatif atau pecahan: false; Number.isInteger menolak pecahan dan nilai bukan number. [2]
  • Bilangan sangat besar: jumlah pangkat bisa melewati 253 − 1 dan kehilangan presisi; sebutkan BigInt bila rentang input besar.

Soal 3: Cek bilangan prima

Soal

Kembalikan true bila n adalah bilangan prima: bilangan bulat lebih dari 1 yang hanya habis dibagi 1 dan dirinya sendiri. Contoh: 2, 3, 7919 → true; 1, 9, 7917 → false.

Pertanyaan klarifikasi

  • Satu angka atau banyak angka sekaligus? (Banyak angka sampai batas N lebih cocok dengan Sieve of Eratosthenes.)
  • Rentang n: sampai berapa?

Ide

Bila n = a × b dengan a ≤ b, maka a ≤ √n. Jadi cukup mencoba pembagi sampai √n. Tangani 2 terpisah, lalu coba hanya pembagi ganjil 3, 5, 7, …

Pseudocode

fungsi isPrime(n):
    jika n bukan integer atau n < 2: kembalikan false
    jika n genap: kembalikan n = 2
    d ← 3
    selama d × d ≤ n:
        jika n mod d = 0: kembalikan false
        d ← d + 2
    kembalikan true

Implementasi JavaScript

function isPrime(n) {
  if (!Number.isInteger(n) || n < 2) return false;
  if (n % 2 === 0) return n === 2;
  for (let d = 3; d * d <= n; d += 2) {
    if (n % d === 0) return false;
  }
  return true;
}

Kompleksitas

Waktu O(√n), ruang O(1).

Edge case

  • 0, 1, dan bilangan negatif: bukan prima.
  • 2: satu-satunya prima genap, ditangani sebelum loop ganjil.
  • Kuadrat prima (9, 25, 49): syarat d × d ≤ n (bukan <) supaya pembagi √n ikut dicoba.
  • Pecahan (2.5): false lewat Number.isInteger. [2]

Soal 4: Merge dua array terurut

Soal

Diberikan dua array integer a dan b yang masing-masing terurut naik, kembalikan satu array terurut berisi semua elemen keduanya. Contoh: [1, 3, 5] dan [2, 4, 6, 8] → [1, 2, 3, 4, 5, 6, 8].

Pertanyaan klarifikasi

  • Boleh membuat array baru, atau harus in-place (mis. a punya ruang kosong di belakang)?
  • Duplikat dipertahankan?

Ide

Two pointers, satu di setiap array. Ambil yang lebih kecil dari dua kepala, majukan pointer-nya. Saat salah satu habis, salin sisa array lainnya. Menggabung lalu sort() juga benar tapi O((n + m) log(n + m)) dan, tanpa comparator, mengurutkan angka sebagai string. [3]

Pseudocode

fungsi mergeSorted(a, b):
    hasil ← [];  i ← 0;  j ← 0
    selama i < panjang(a) dan j < panjang(b):
        jika a[i] ≤ b[j]: tambahkan a[i]; i ← i + 1
        selain itu: tambahkan b[j]; j ← j + 1
    tambahkan sisa a[i..] dan sisa b[j..]
    kembalikan hasil

Implementasi JavaScript

function mergeSorted(a, b) {
  const out = [];
  let i = 0, j = 0;
  while (i < a.length && j < b.length) {
    if (a[i] <= b[j]) out.push(a[i++]);
    else out.push(b[j++]);
  }
  while (i < a.length) out.push(a[i++]);
  while (j < b.length) out.push(b[j++]);
  return out;
}

Kompleksitas

Waktu O(n + m), ruang O(n + m) untuk hasil.

Edge case

  • Salah satu atau kedua array kosong: hasilnya salinan array lainnya, atau [].
  • Nilai sama di kedua array: ≤ mengambil dari a dulu, sehingga urutan stabil.
  • Panjang sangat berbeda: dua loop sisa menangani ekornya.

Soal 5: Karakter pertama yang tidak berulang

Soal

Diberikan string s, kembalikan index karakter pertama yang hanya muncul sekali, atau -1 bila tidak ada. Contoh: "leetcode" → 0, "loveleetcode" → 2, "aabb" → -1.

Pertanyaan klarifikasi

  • Huruf besar dan kecil dibedakan?
  • Index dalam karakter (code point) atau dalam unit UTF-16 bila ada emoji?

Ide

Dua kali lewat: pertama hitung frekuensi setiap karakter dengan Map [4], kedua cari dari kiri karakter pertama yang hitungannya 1.

Pseudocode

fungsi firstUniqChar(s):
    hitung ← map kosong
    untuk setiap karakter c di s: hitung[c] ← hitung[c] + 1
    untuk i dari 0 sampai n − 1:
        jika hitung[s[i]] = 1: kembalikan i
    kembalikan −1

Implementasi JavaScript

function firstUniqChar(s) {
  const chars = [...s];                // per code point
  const count = new Map();
  for (const ch of chars) count.set(ch, (count.get(ch) ?? 0) + 1);
  for (let i = 0; i < chars.length; i++) {
    if (count.get(chars[i]) === 1) return i;
  }
  return -1;
}

Kompleksitas

Waktu O(n), ruang O(k) untuk k karakter berbeda (O(1) bila alfabet tetap, mis. a–z).

Edge case

  • String kosong: -1.
  • Semua karakter berulang: -1.
  • Satu karakter: 0.
  • indexOf dan lastIndexOf per karakter juga benar tapi O(n²).

Soal 6: Rotate array

Soal

Putar array nums ke kanan sebanyak k langkah, in-place. Contoh: [1, 2, 3, 4, 5, 6, 7], k = 3 → [5, 6, 7, 1, 2, 3, 4].

Pertanyaan klarifikasi

  • Ke kanan atau ke kiri? Harus in-place dengan memori O(1)?
  • Bisakah k lebih besar dari panjang array, atau negatif?

Ide

Rotasi k kali sama dengan rotasi k mod n kali. Trik tiga kali balik: balik seluruh array, lalu balik k elemen pertama, lalu balik sisanya. [1..7] → [7,6,5,4,3,2,1] → [5,6,7,4,3,2,1] → [5,6,7,1,2,3,4]. Tukar dua elemen memakai destructuring assignment. [5]

Pseudocode

fungsi rotate(nums, k):
    n ← panjang(nums);  jika n = 0: selesai
    k ← k mod n
    balik(nums, 0, n − 1)
    balik(nums, 0, k − 1)
    balik(nums, k, n − 1)

fungsi balik(nums, lo, hi):
    selama lo < hi: tukar nums[lo] dan nums[hi]; lo ← lo + 1; hi ← hi − 1

Implementasi JavaScript

function rotate(nums, k) {
  const n = nums.length;
  if (n === 0) return nums;
  k = k % n;
  const balik = (lo, hi) => {
    while (lo < hi) {
      [nums[lo], nums[hi]] = [nums[hi], nums[lo]];
      lo++;
      hi--;
    }
  };
  balik(0, n - 1);
  balik(0, k - 1);
  balik(k, n - 1);
  return nums;
}

Kompleksitas

Waktu O(n) (setiap elemen ditukar paling banyak dua kali), ruang O(1).

Edge case

  • k > n: k % n, mis. [1, 2] dengan k = 5 sama dengan k = 1 → [2, 1].
  • k = 0 atau k = n: array tidak berubah.
  • Array kosong: dicek sebelum k % n supaya tidak membagi dengan nol (k % 0 menghasilkan NaN).
  • k negatif (rotasi ke kiri): klarifikasi dulu; bila diizinkan, pakai ((k % n) + n) % n.

Soal 7: Max subarray (algoritma Kadane)

Soal

Diberikan array integer tidak kosong nums, kembalikan jumlah terbesar dari subarray yang bersebelahan (minimal satu elemen). Contoh: [-2, 1, -3, 4, -1, 2, 1, -5, 4] → 6 (subarray [4, -1, 2, 1]).

Pertanyaan klarifikasi

  • Bila semua angka negatif, apakah jawabannya angka terbesar atau 0 (subarray kosong)?
  • Yang diminta jumlahnya saja, atau juga posisi awal dan akhirnya?

Ide

Untuk setiap posisi i, subarray terbaik yang berakhir di i adalah nums[i] sendiri atau subarray terbaik yang berakhir di i − 1 ditambah nums[i]; ambil yang lebih besar. Jawaban akhir adalah maksimum dari semua nilai itu. Bila jumlah berjalan sudah negatif, ia hanya merugikan, jadi mulai baru.

Pseudocode

fungsi maxSubArray(nums):
    sekarang ← nums[0];  terbaik ← nums[0]
    untuk i dari 1 sampai n − 1:
        sekarang ← maks(nums[i], sekarang + nums[i])
        terbaik ← maks(terbaik, sekarang)
    kembalikan terbaik

Implementasi JavaScript

function maxSubArray(nums) {
  let cur = nums[0], best = nums[0];
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    best = Math.max(best, cur);
  }
  return best;
}

Kompleksitas

Waktu O(n), ruang O(1). Brute force semua subarray O(n²).

Edge case

  • Semua negatif ([-3, -1, -2]): -1, karena inisialisasi dengan nums[0], bukan 0. Menginisialisasi best = 0 adalah bug paling umum.
  • Satu elemen: elemen itu sendiri.
  • Array kosong: nums[0] bernilai undefined; tanyakan kontraknya dan lempar error atau kembalikan nilai yang disepakati. Math.max() tanpa argumen menghasilkan -Infinity. [6]

Soal 8: Valid anagram dengan array hitungan (a–z)

Soal

Sama dengan Lesson 0008 soal 3, tapi input dijamin hanya huruf kecil a–z, dan interviewer meminta solusi tanpa Map.

Pertanyaan klarifikasi

  • Dijamin hanya a–z? Bila input bisa berisi karakter lain, versi Map dari 0008 lebih aman.
  • Huruf besar perlu diubah ke kecil dulu?

Ide

Alfabet tetap 26 huruf, jadi pakai array 26 angka sebagai penghitung. Index huruf = kode karakter dikurangi kode "a" (charCodeAt mengembalikan unit UTF-16 sebagai angka [7]). Tambah untuk s, kurangi untuk t dalam satu loop; anagram bila semua hitungan kembali 0.

Pseudocode

fungsi isAnagramAZ(s, t):
    jika panjang(s) ≠ panjang(t): kembalikan false
    hitung ← array 26 berisi 0
    untuk i dari 0 sampai n − 1:
        hitung[s[i] − 'a'] ← +1
        hitung[t[i] − 'a'] ← −1
    kembalikan semua hitung = 0

Implementasi JavaScript

function isAnagramAZ(s, t) {
  if (s.length !== t.length) return false;
  const count = new Array(26).fill(0);
  const a = "a".charCodeAt(0);
  for (let i = 0; i < s.length; i++) {
    count[s.charCodeAt(i) - a]++;
    count[t.charCodeAt(i) - a]--;
  }
  return count.every(c => c === 0);
}

Kompleksitas

Waktu O(n), ruang O(1) (array tetap 26 elemen, tidak tumbuh dengan input).

Edge case

  • Panjang berbeda: false sebelum loop.
  • Dua string kosong: true.
  • Karakter di luar a–z membuat index negatif atau > 25 dan hasilnya salah tanpa error: ini alasan pertanyaan klarifikasi pertama.
