Review campuran database

Tanpa materi baru. Soal kuis dan lisan dari lesson 0019–0023, diacak bersama dua topik performa EF Core dari 0006 (N+1 dan AsNoTracking).

Target lesson ini: tahu dengan jujur topik database mana (SQL dasar, Stored Procedure, transaction dan locking, index, optimasi query) yang benar-benar menempel, sehingga Anda bisa menjawab "query ini lambat, apa yang Anda lakukan?" di interview tanpa ragu. Topik yang masih lemah masuk ke daftar ulang sebelum interview.

Aturan main

  1. Jangan buka catatan, lesson lama, reference, atau SSMS. Yang diuji adalah kemampuan menjawab seperti di interview. Kalau Anda mengintip, hasilnya tidak berarti.
  2. Soal kuis: pilih satu jawaban. Ada satu soal kuis untuk setiap topik lesson 0019–0023 dan untuk dua topik 0006, jadi setiap topik diuji minimal sekali (29 kuis).
  3. Soal lisan: jawab dengan suara keras (±60 detik, boleh direkam di ponsel) sebelum membuka checklist. Untuk soal "tulis SP" atau "tulis query", ucapkan atau tulis di kertas dulu, baru buka checklist. Lalu centang poin yang benar-benar Anda sebut, bukan yang "sebenarnya tahu".
  4. Kriteria lulus per topik (sama seperti review 0007 dan 0012): soal kuis acak dijawab benar, dan jawaban lisan memenuhi minimal 4 dari 6 poin checklist. Satu kesalahan di topik itu = topik lemah. Topik yang kuisnya benar tapi tidak mendapat soal lisan tampil sebagai Kuis lulus, lisan belum diuji dan belum dihitung lulus.

Urutan soal mengikuti seed yang tampil di bawah. Tombol "Acak ulang" membuat set baru, tapi kerjakan set pertama sampai selesai sebelum mengacak ulang. Hasil set pertama itulah yang dilaporkan. Kalau ingin mengulang set yang sama nanti, tambahkan ?seed=NNN di URL. Soal lisan ditarik 6 dari 13 yang ada, jadi topik yang belum dapat soal lisan bisa diuji lewat ?seed= lain di sesi berikutnya (pengulangan berjarak).

Setelah selesai: laporkan hasilnya ke agent

  1. Setelah semua soal dijawab, ringkasan per topik muncul di bawah soal terakhir.
  2. Tekan Salin (atau blok teks di kotak ringkasan), lalu tempel ke agent di terminal, misalnya: "Ini hasil review 0024, tolong dicatat."
  3. Agent akan menulis learning record "sudah dikuasai" hanya untuk topik yang lulus (kuis benar dan lisan minimal 4 dari 6), dengan seed dan skor sebagai bukti. Topik Kuis lulus, lisan belum diuji dicatat di NOTES saja, tanpa learning record.
  4. Topik yang lemah dicatat sebagai baris "Topik lemah 0024: …" di NOTES dan masuk ke bagian 2b ulang sebelum interview.

Untuk topik database, hanya hasil review 0024 yang dicatat sebagai bukti penguasaan. Skor kuis di lesson 0019–0023 dan hasil lab di SQL Server tidak dihitung.

Kalau ada topik lemah

Jangan baca ulang seluruh lesson. Buka hanya bagian reference untuk topik itu (±5 menit), lalu tutup dan coba jelaskan lagi dengan suara keras. Kalau topik lemahnya soal menulis query (top-N per grup, SP dengan TRY/CATCH, index covering, keyset pagination), ulangi latihan tulis query di lesson asalnya tanpa melihat jawaban, lalu jalankan di SQL Server bila container lab tersedia. Kerangka jawaban 30 detik untuk semua topik database ada di bagian 3b ulang sebelum interview.

Bacaan utama (hanya untuk topik lemah, setelah review) SQL dasar · Stored Procedure · Transaction & locking · Index · Optimasi query · EF Core (N+1, AsNoTracking). Sumber resminya (Microsoft Learn: SQL Server, T-SQL, EF Core) dikutip di masing-masing reference dan tercatat di RESOURCES.md.
