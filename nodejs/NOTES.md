- Track mandiri (ADR 0003): lesson tidak merujuk atau menautkan track lain. - Spec dan keputusan: `.scratch/materi-nodejs/spec.md`. Konvensi umum: `docs/adr/0003-konvensi-materi-baru.md`.

- Tanpa lab. Contoh kode pendek untuk dibaca (sebaiknya ≤ 20 baris per blok). Live coding dilatih lewat soal `oral` bertipe "tulis kode": `sample` berisi jawaban kode, `checklist` berisi poin penilaian. Setiap modul NestJS (0016 ke atas, kecuali review) memuat minimal satu soal "tulis kode".
