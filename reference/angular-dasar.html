Component

@Component({ selector: 'app-product-card', templateUrl: './x.html', styleUrls: ['./x.css'] })
export class ProductCardComponent {
  @Input() product!: Product;                       // parent → child  (props)
  @Output() deleted = new EventEmitter<number>();   // child → parent  (callback prop)
}

Standalone component: standalone: true + imports: [...] di @Component, tanpa NgModule; bootstrap lewat bootstrapApplication(AppComponent). Jangan dimasukkan ke declarations. Default ng new v16 masih NgModule (kecuali --standalone).

Structural directive

<p *ngIf="loading; else done">Memuat…</p>  <ng-template #done>…</ng-template>
<li *ngFor="let p of products; trackBy: trackById; let i = index">{{ i }}. {{ p.name }}</li>
<div [ngSwitch]="status"><span *ngSwitchCase="'active'">Aktif</span><span *ngSwitchDefault>–</span></div>
<ng-container *ngIf="isAdmin">…</ng-container>   <!-- seperti Fragment -->
  • * = singkatan untuk <ng-template>. Hanya satu structural directive per elemen; gabungkan dengan <ng-container>.
  • trackBy ≈ key di React.

Jebakan interview

  1. Fetch data di constructor → pindahkan ke ngOnInit.
  2. "Can't bind to 'ngModel'" → FormsModule belum ada di imports.
  3. Module lain dimasukkan ke declarations → seharusnya imports.
  4. Menjawab dengan @if/@for → itu Angular 17.
