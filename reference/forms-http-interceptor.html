HttpClient

  • HttpClientModule di AppModule; inject HttpClient ke Angular Service.
  • Semua method mengembalikan Observable cold: tanpa subscribe (atau | async) tidak ada request.
  • get<Product[]>() = type assertion compile-time saja. Pakai interface.
  • Error: HttpErrorResponse. Server → status 4xx/5xx; jaringan → status === 0.
  • pipe(retry(2), catchError(...)). retry = subscribe ulang = request ulang.

HTTP Interceptor

@Injectable()
export class AuthInterceptor implements HttpInterceptor {
  intercept(req: HttpRequest<unknown>, next: HttpHandler) {
    const authReq = req.clone({ setHeaders: { Authorization: `Bearer ${token}` } });
    return next.handle(authReq).pipe(catchError(e => { /* 401 → login */ return throwError(() => e); }));
  }
}
providers: [{ provide: HTTP_INTERCEPTORS, useClass: AuthInterceptor, multi: true }]
AturanKenapa
req.clone(...), jangan ubah reqHttpRequest readonly; retry harus melihat request yang sama
Panggil next.handle(req)teruskan ke interceptor berikutnya; terakhir HttpBackend
multi: truetoken berisi array interceptor; sediakan di injector yang sama dengan HttpClientModule
Urutan = urutan providerrequest A → B, response B → A; tidak bisa diubah setelahnya
Kegunaanheader auth, logging/timing, cache, error global (401), XSRF

Versi fungsi (standalone): HttpInterceptorFn + provideHttpClient(withInterceptors([...])), boleh inject().

Padanan: Axios interceptors.request/response.use (React) · Express middleware next() (backend). Glosarium: HTTP Interceptor, bukan "middleware".
