# Prior knowledge: system design dimulai dari nol

User meminta materi system design "dari awal". Pengalaman developer sehari-hari ada (stack TypeScript/Node.js/React, REST, JSON), tapi system design belum pernah dipelajari secara terstruktur dan belum diukur. User eksplisit tidak mau terlihat over-engineer (contoh: memilih microservices untuk 1.000 user).

**Implications:** jangan menganggap istilah infrastruktur (load balancer, replication, queue) sudah dikenal. Jelaskan dari motivasinya: masalah apa yang muncul tanpa komponen itu, dan pada angka berapa. Setiap komponen diajarkan bersama "kapan tidak perlu".
